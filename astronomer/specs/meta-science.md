# BEAR Meta Science

*A crypto meta is a temporary coordination regime in which a coherent narrative causes attention, capital, product activity and social behaviour to become mutually reinforcing across a related set of assets.*

---

## The Meta Lifecycle

```
M0 DORMANT → M1 SEED → M2 INFORMED_DISCOVERY → M3 INDEPENDENT_VALIDATION
→ M4 REFLEXIVE_ACCELERATION → M5 AMPLIFICATION → M6 SATURATION → M7 DECAY
```
