## Acquisition scoring function (price-blind)

```
Priority = .25U + .20E + .20F + .15T + .10I + .10C
```

Where:
- U = uniqueness of information
- E = machine extractability
- F = falsifiability
- T = temporal specificity
- I = independence from existing sources
- C = coverage / cadence

**No historical return or win rate in this calculation.**
