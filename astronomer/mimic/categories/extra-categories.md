# Extra categories the data forced on us

Beyond voters/verdicts/feeds, the clustering surfaced these buckets:

1. **EXIT reporters** (partial/close posts with numbers → MFE/partial modeling).
   Best: Crypto_Chase (3.2%), CryptoBheem (5.0%), DrProfit (3.9%).
   Chase's "took 75% off +31.5%" format is the template. Almost nobody else does this.
2. **CONDITIONAL inventory** (if-X-then-Y triggers → conditional votes on activation).
   Best: RektProof (16% — highest anywhere), Daan (14%), DrProfit (8%), Pentosh (7%).
3. **LEAN-tactical** (directional lean, no levels — useless WITHOUT the chart).
   Biggest: FlowHorse (152), SalsaTekila (111), theunipcs (100), Wild_Randomness (31% of 816).
   LEAN splits 13% tactical / 80% data-alerts / 7% promo-spam (`bitget/vip/cfd` → drop).
4. **MICROSTRUCTURE** (causal flow features, never full-strength votes).
   52kskew (who→where→spot/perp→OI→CVD→premium→level) + Husslin_ (dealer inventory
   proxy) + laevitas1 + kingfisher_btc. Femd into: Skew interpretation + raw Binance data.
5. **SMART MONEY** (`wallet_position × ex_ante_skill × horizon × asset`, never raw size).
   HyperTracker (cohorts + 10-mo history API) + Hyperliquid raw API + OnchainLens +
   Lookonchain + eyeonchains (forensic interpretation) + ZachXBT (counterparty clustering).
   Discovered rule: giant anonymous + negative lifetime PnL = fade, not follow.
6. **FORENSIC_EVENT** (proven-vs-speculation investigations): eyeonchains, ZachXBT.
   Event feature with evidence grades, not a vote.
7. **RV/CARRY** (new model head, not directional): liquiditygoblin
   (funding/basis/spread/borrow/fees/breakeven arithmetic; PROTECTED — Substack path).
   `P(RV profitable | funding,basis,spread,borrow,fees,liquidity)`.
8. **CATALYST / TOKEN MICROECONOMICS**: NachoTrades (event entries, experiment),
   that1618guy (fee/burn/TWAP dashboards, alts only).
9. **EDUCATORS** (reasoning teachers): CryptoCred, Bluntz (narrative), _Checkmatey_.
10. **CHATTER sinks** (reply-heavy, lowest $/call): 0xnobi, SalsaTekila (66% replies),
    ByzGeneral, trader1sz-firehose (off-X value on tradersz.com instead).

Routing: CALL→voters · EXIT→exit model · COND→trigger inventory ·
VERDICT→regime votes · FLOW/MACRO→features · MICROSTRUCTURE→causal features ·
SMART_MONEY→skill-weighted positions · FORENSIC→event flags · RV→carry head ·
LEAN→chart-paired only · EDU→reasoning corpus · CHATTER→drop.
